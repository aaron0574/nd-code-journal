I'm **Aaron Greene**, senior web designer and developer at the University of Notre Dame. Most of my week is spent building and maintaining sites for campus units — which means solving the same kinds of problems over and over: accessible components, flexible layouts, CMS templates, performance fixes.

This journal is where those solutions go so they don't get lost in a closed ticket or an old branch.

## How to use it

- **Search** covers the full text of every article and code sample.
- **Articles** can be filtered by topic and language, and sorted.
- Every code block has a **Copy** button. Code is MIT licensed — take it.
- Look for **live demos**; flip to the *Code* tab to see the full source.
